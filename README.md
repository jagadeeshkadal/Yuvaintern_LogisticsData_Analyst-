# Last-Mile Delivery Performance Analysis and Optimization

YuvaIntern – Logistics Data Analyst Internship

## Project
This repository supports a four-week logistics analytics project using the LaDe-D last-mile delivery dataset.

### Planned progression
1. Week 1 – Strategic planning and data exploration
2. Week 2 – Data collection, cleaning and preprocessing
3. Week 3 – EDA and visualization
4. Week 4 – Predictive modeling and optimization

## Dataset
LaDe – The First Comprehensive Last-mile Delivery Dataset from Industry:
https://github.com/wenhaomin/LaDe

LaDe-D is the package delivery component. The full dataset is large, so the project will use a documented city-level subset.

## Week 1 scope
- Define the last-mile delivery business problem
- Define KPIs
- Research the dataset and logistics context
- Design the end-to-end analytical roadmap
- Provide Python implementation illustrations

## Important
Week 1 contains a plan, not fabricated analytical results. Actual data-quality findings, EDA results, model metrics, and optimization results will be added in Weeks 2–4 after execution.
